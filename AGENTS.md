# Seller Hub Frontend

Baca [panduan pusat Seller Hub](../seller-hub-specs/AGENTS.md) dan pilih bagian tugas di [Panduan kerja agent](../seller-hub-specs/docs/AGENT-GUIDE.md). Untuk pekerjaan fitur atau perubahan perilaku bisnis, gunakan [alur fitur dan keputusan](../seller-hub-specs/docs/FEATURE-WORKFLOW.md).

Path repo saudara dihitung dari root repo ini. Jika specs tidak tersedia, laporkan batasnya dan lanjutkan pekerjaan teknis independen menggunakan kode dan tooling lokal. Pertahankan perubahan pengguna. Commit, push, deploy dan perubahan database live memerlukan instruksi pengguna.

- Verifikasi dan keamanan → [Testing](../seller-hub-specs/docs/FE/TESTING.md) dan [Security](../seller-hub-specs/docs/FE/SECURITY.md).
- Setup, CI dan pekerjaan teknis → [Setup](../seller-hub-specs/docs/FE/SETUP.md) dan [TODO](../seller-hub-specs/docs/FE/TODO.md).
